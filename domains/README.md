Tamanna AI Domain System

Owner: HM INSAN ALI

Domain Architecture

* tamanna.com — Primary website
* www.tamanna.com — Primary website URL
* tamanna.io — Redirect to primary website
* api.tamanna.com — Backend API
* admin.tamanna.com — Administration panel
* Tor v3 Hidden Service — Optional private access

Deployment Requirements

1. Register the public domains.
2. Configure DNS records to point to the server.
3. Configure Nginx.
4. Issue valid HTTPS certificates.
5. Configure the Tor Hidden Service separately if enabled.

Security

* Never commit .env files or private keys.
* Keep TLS certificates and Tor private keys on the server.
* Do not enable the onion service until its server configuration is tested.
